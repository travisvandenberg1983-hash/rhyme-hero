# Rhyme Hero

Train your rhyming super-skills. Rhyme Hero is a coach: it hands you word banks, stress patterns and questions - **you** write the lines.

```
rhyme-hero/
├── engine/   Python 3.11 + FastAPI  (http://localhost:8000)
└── web/      React + Vite + TypeScript + Tailwind, PWA  (http://localhost:5173)
```

The UI talks to the engine only over HTTP, so run both.

## Prerequisites

- Python **3.11**
- Node.js **20.19+** or **22.12+** (required by Vite 7) and npm

## Engine

```bash
cd engine
python -m venv .venv
# Windows: .venv\Scripts\activate    macOS/Linux: source .venv/bin/activate
pip install -e ".[dev]"
uvicorn app.main:app --reload --port 8000
```

- Health check: http://localhost:8000/health
- Interactive API docs: http://localhost:8000/docs
- Tests: `pytest`

Allowed browser origins are set by `RHYME_HERO_CORS_ORIGINS` (see `engine/.env.example`); the defaults cover the Vite dev and preview servers.

## Web

```bash
cd web
npm install
cp .env.example .env.local   # Windows PowerShell: Copy-Item .env.example .env.local
npm run dev
```

Open http://localhost:5173. `VITE_ENGINE_URL` in `.env.local` points the UI at the engine (default `http://localhost:8000`).

### PWA

The service worker is generated by `vite-plugin-pwa` on build. To test install/offline behaviour:

```bash
npm run build
npm run preview
```

Then open http://localhost:4173 and use the browser's install button.

## Project rules

See [CLAUDE.md](CLAUDE.md): the app never writes finished lines, follows a comic-book visual style with original characters only, and keeps engine and UI separate.
